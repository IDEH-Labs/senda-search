About Senda

Senda is an independent, libre, and verifiable web search engine built from the ground up to protect user privacy and digital autonomy.

Principles

  • Free Software: Governed by the GNU GPL-3.0-or-later license. Auditable and verifiable.
  • Independent Crawler: Autonomous index strictly respecting robots.txt (RFC 9309).
  • Zero Profiling: No user tracking, no search history retention, and zero cookies.
  • Transparent Ranking: Deterministic BM25 retrieval across authentic web documents.

Project

Engineered and maintained by IDEH Labs.
