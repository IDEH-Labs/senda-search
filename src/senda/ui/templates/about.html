About Senda

Senda is an independent, auditable, and ethical web search engine built from the ground up to defend user autonomy, information sovereignty, and the Free Software movement.

Ethical Foundation: The 4 Freedoms

Senda adheres strictly to the four essential software freedoms formulated by the Free Software Foundation:

  • Freedom 0: The freedom to run the program as you wish, for any purpose.
  • Freedom 1: The freedom to study how the program works, and change it so it does your computing as you wish.
  • Freedom 2: The freedom to redistribute copies so you can help others.
  • Freedom 3: The freedom to distribute copies of your modified versions to others.

Architectural Principles

  • Sovereign Crawling: Senda operates its own independent crawler respecting RFC 9309 robots.txt and strict domain politeness intervals.
  • Defense in Depth: Anti-SSRF (Server-Side Request Forgery) IP verification blocks any access to private, loopback, or cloud metadata endpoints.
  • No Telemetry: No third-party trackers, no tracking pixels, no behavioral analytics.
  • Transparent Ranking: Deterministic BM25 retrieval with open, auditable field weightings and zero sponsored manipulation.
