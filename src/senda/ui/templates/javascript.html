JavaScript y Licencias de Software

Senda utiliza JavaScript únicamente para mejoras progresivas y opcionales de interfaz: selección de categoría en la portada y persistencia local de preferencias como el tema visual. La búsqueda básica, paginación y filtros funcionan con formularios HTTP convencionales sin requerir JavaScript.

Todos los scripts distribuidos por Senda son Software Libre bajo licencia GNU GPL-3.0-or-later y su código fuente sin ofuscar está disponible en /static/js/. La siguiente tabla sigue el formato de etiquetas web (Web Labels) para GNU LibreJS. No se ha realizado una verificación formal automatizada con dicha extensión.
